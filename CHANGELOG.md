# Changelog (на русском)

LLM управляет текущей вкладкой: облачные API и локальные модели (LM Studio, Ollama, llama.cpp, Jan, vLLM).

## Установка / обновление
1. `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» (или ↻ у установленного).
2. Иконка расширения открывает боковую панель. Шестерёнка → провайдер, ключ, модель.

## Интерфейс (v0.4)
Главный экран: статус с кольцом шагов, выбранная модель, лог и ввод задачи. Режим мышления (Быстро / Авто / Думать) выбирается над полем ввода. Шестерёнка сверху открывает настройки провайдера, модели, скриншотов и темы; заметки сайтов доступны внизу настроек.

## Скилы сайтов
- «Изучить сайт» читает **только текущую страницу** через DOM и отправляет модели название, URL без query-строки, подписи видимых элементов и строки с `<kbd>` (без значений полей и общего текста документа). Можно задать тему изучения; агент не нажимает кнопки и не ходит по ссылкам. Результат открывается как черновик: проверьте факты и нажмите «Сохранить скил». Подписи интерфейса тоже могут содержать личные данные — не используйте изучение на чувствительных страницах.
- «Скилы сайтов» позволяют добавлять подсказки вручную, редактировать, отключать и удалять их. Данные хранятся локально (`chrome.storage.local`) отдельно от заметок агента; ограничение — 20 на домен. Путь `/editor` ограничивает применение разделом `/editor` и его вложенными страницами, пустой путь — всем сайтом.
- При выполнении задачи до шести включённых подсказок текущего домена/раздела подаются модели; после навигации набор обновляется. Подсказки не заменяют проверку состояния страницы или подтверждение рискованных действий. Изучение canvas и интерфейсов внутри iframe ограничено доступной DOM-структурой; бинды, которых нет на странице, нужно вносить вручную или изучать на странице документации.

## v0.7.5
Спасибо [@ChernStepanov](https://github.com/ChernStepanov) за код-ревью: аудит нашёл ошибки ниже.

**Безопасность /skript**
- Проверка кода разбирает выражения `${…}` в шаблонных строках и регулярные выражения: через них прятался `fetch`.
- Закрыты обходы: ссылка на `fetch`, `this[…]`, `Reflect`, `import()`, весь глобальный объект как значение.
- Запрещена загрузка внешних ресурсов через DOM: `src`/`srcset`, `new Image/Audio/Worker`, `innerHTML`, `insertAdjacentHTML`, `setAttribute("src", …)`, CSS `url()`, `window.open`.
- Переход «только по своему сайту» сравнивает origin (схема + хост + порт), а не только имя хоста.
- `el.style.top = …` больше не считается навигацией.

**Исправления**
- С локальными моделями /skript работает: компактный и JSON-режим не отбрасывают его инструменты.
- Скриншот берётся из окна текущей вкладки.
- `limit` у `query_dom`/`fetch_page` ограничен 1..100.
- «Сохранить для сайта» помнит запись в библиотеке: повторное сохранение обновляет её, а не создаёт дубль.
- Сохранённый скрипт для `/editor` не предлагается на `/editorial`.
- Отказ запуска скрипта не оставляет висеть кнопки ответа и флаг «скрипт работает».
- Пересохранение с тем же кодом обновляет параметры скрипта.
- Цикл скрипта не копит таймеры.
- Оценки, заметки и подсказки пишутся по очереди и не затирают друг друга.
- «Обновиться» удаляет файлы прошлой версии, которых нет в новой (только записанные самим обновлением).
- Меньше нагрузки: поиск карточек в `extract_items`, цели щупалец, линии тура.
- Старая настройка компактного режима (`true`/`false`) переносится правильно.

## v0.6
**Поиск и ответы**
- `extract_items`: список товаров/объявлений одним вызовом (JSON-LD, microdata, карточки с ценой — берётся лучший способ), до 100 позиций без тихой обрезки, сортировка по цене, текущая страница или url того же сайта в фоне.
- Ответ-список: «- [название](ссылка) — **цена** · детали» показывается списком с ценой справа и миниатюрой; ссылки и фото подставляются по совпадению цены и названия. Перечисление одной строкой («1) … ; 2) …») и нумерованные строки сами разбиваются на пункты.
- Кнопка «Ещё» — следующие результаты без уже показанных; пометка «⚠» у цен сильно ниже медианы.
- Оценка ответа «хорошо/плохо» с комментарием; отзывы «плохо» копируются из настроек. Заметки о качественном поиске — `docs/SEARCH_NOTES.md`.

**Задачи и агент**
- Вложения к задаче: картинки (до 4) и текстовые файлы (до 5) — 📎, вставка, перетаскивание. Модель видит их как данные, а не команды; сами файлы не сохраняются.
- Скриншоты по делу: на 1-м шаге, после неудачи, на «пустых» страницах; если на экране крупный canvas/video (игры, редакторы) — на каждом шаге. Инструмент `vision` работает.
- Старые результаты инструментов сжимаются; `click_at` сообщает, что под курсором. Клик по элементу, закрытому баннером/модалкой/липкой шапкой, ищет открытую точку элемента, а если её нет — модель узнаёт, что мешает.
- «Стоп» прерывает текущее действие сразу; панель больше не залипает в «работаю».
- Карточка скрипта у поля ввода: одна на скрипт, повторы — счётчик ×N, новая версия сворачивает старую; после завершения остаётся с итогом.
- Onshape: проверка несуществующих значений перечислений (`BooleanOperationType.ADD`) и точек без единиц, предупреждения перестроения, подсчёт тел в Part Studio.

**Интерфейс**
- Рисунок «звёздная сеть» (мозг, WebGL2) вместо точечного: реагирует на ввод, размышление, действия, подтверждения, ошибки и «Стоп»; засыпает после минуты простоя; под мозгом — фраза точками.
- Щупальца на странице (декоративные): пока агент работает, впиваются в элементы и «выкачивают» их; вёрстку не трогают, перед снимками экрана прячутся. Виды — «Обычные / Корни / Трещины», выключаются в настройках «Движение».
- Быстрый выбор модели кликом по её названию в шапке: поиск, недавние (в том числе у других провайдеров), «Настройки подключения…».
- Обучение при первом запуске: подсветка кнопок и карточка с пояснениями; повторить — из настроек.

**Проект**
- Раскладка по папкам: `panel/`, `art/`, `page/`, `skript/`, `docs/`; тесты рядом с модулями, все разом — `./test.sh`.

## v0.5.3
- «Подбирать палитру под сайт» теперь копирует страницу целиком: светлая/тёмная панель по фону сайта, цвет текста, поверхности, рамки, цвет главной кнопки (или бренд-цвет/ссылок) и цвет текста на ней. Контраст проверяется (WCAG): если цвет сливается с фоном, меняется только светлота. Тема «Светлая/Тёмная» при включённом тумблере не используется.
- Фон берётся из DOM по сетке точек, цвета в oklch/color-mix читаются корректно; если фон — картинка/градиент, используется скриншот. Палитра обновляется каждые 6 с и при смене вкладки/страницы.

- Верхний блик в арте переделан: чёткий луч, продолжающий шип картинки, с мягким свечением, четырёхлучевой звёздочкой и длинным горизонтальным бликом на конце. Блик «выстреливает» от картинки к кончику при появлении арта. Зеркальное продолжение у стыка оставлено только для редкой пыли.

## v0.5.2
- В настройках темы появился тумблер «Подбирать палитру под сайт» (вместо кружка «Авто»). Включён — палитра подстраивается под цвет текущей вкладки, ручные акценты приглушены. Выключен — используется выбранный вручную акцент (он запоминается).
- Подбор цвета теперь сначала смотрит на сами элементы страницы (кнопки, ссылки, заголовки, CSS-переменные бренда), а скриншот остался запасным вариантом с более мягкими порогами. Диагностика: консоль панели (ПКМ по панели → «Проверить»), префикс `[autoPalette]`.

## v0.5.1
- Акцент «Авто» (по умолчанию): цвет берётся из theme-color сайта или из доминирующего цвета видимой области вкладки; подкрашиваются акценты, поверхности и арт. Серая/бесцветная страница даёт нейтральный монохром.
- Серые поверхности стали строго нейтральными (раньше слегка синили).
- Арт крупнее, сверху дорисован свой фрагмент (вспышка, звёзды, «+»).
- Убраны поясняющие подписи в настройках; токены и время показываются только после первого запуска.

## Редизайн v0.5
- Убраны лишние элементы: пиксельная фигурка, кольцо шагов, чип «Эта вкладка», дубли подсказок, плашка-слоган, моноширинный шрифт в интерфейсе.
- Рабочие акценты (синий, зелёный, оранжевый, фиолетовый, розовый, монохром) — окрашивают кнопки, переключатели, фокус, сообщения пользователя и индикатор шагов. Цвета подобраны отдельно под тёмную и светлую тему.
- Полноценная светлая тема; единые скругления (--r-lg / --r-md / --r-pill) везде, включая настройки, select и диалог подтверждения.
- Фон чата — единая точечная композиция из исходного арта и звёздного поля без границы между ними. При изменении размеров панели вся композиция масштабируется с сохранением пропорций и обрезается по краям. Все точки участвуют в одной волне от стыка к краям и луче к звезде (~1,2 с). Данные изображения, луч и анимация в одном `art.js`. Цвет берётся из акцента темы (`--acc`), включая автоматическую палитру сайта. При снижении анимации рисунок показывается сразу.
- Рамка и подпись «нажимает/вводит» на странице больше не рисуются.

## Что исправлено в v0.4
- Карточки в настройках больше не обрезаются (поле «Модель», ↻ и «Проверить» были недоступны).
- Модель выбирается автоматически: список подтягивается при выборе провайдера и открытии настроек; при запуске без модели берётся загруженная (LM Studio: через /api/v0/models, с признаками vision/контекст). Эмбеддинг-модели скрыты.
- «Формат действий: Авто»: сначала нативные tools, при отсутствии поддержки сам переключается на JSON.
- Компактный режим для малого контекста (авто для локальных): короткий промпт, 13 инструментов, 60 элементов страницы, обрезка истории + краткая память о шагах.
- Модели с <think>…</think> (Qwen3, DeepSeek-R1 и др.) разбираются корректно.
- Если модель не принимает картинки, скриншоты отключаются сами и запрос повторяется.
- Ошибки переполнения контекста объясняются понятным текстом.

## Ограничения
- iframe не поддерживаются в snapshot; нет загрузки файлов.
- Не работает на chrome://, Chrome Web Store и PDF-viewer.
